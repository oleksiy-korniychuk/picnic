# Progression System Design (v0.1)

## Overview
Roguelike progression with permadeath. Each stalker has one life - death resets everything (map, stash, contracts). Players manage a base stash, select contracts, prepare loadouts, and choose between selling items for base value, turning them in for contract bonuses, or keeping them for future runs.

## Core Loop

```
Base Hub (Stash + Contracts)
  ↓
Prepare Loadout (move items: stash → run inventory)
  ↓
Enter Zone
  ↓
Survive + Loot
  ↓
Extract OR Die
  ↓
├─ Extract → Return to Base with loot
│   ├─ Move items between run inventory ↔ stash
│   ├─ Sell items for money
│   ├─ Turn in items for contracts (bonus rewards)
│   └─ Repeat
│
└─ Die → PERMADEATH
    ├─ New stalker, reset map + stash + contracts + money
    └─ Start over
```

## Base Hub Structure

**Two modal screens:**

### 1. Stash Management (default screen)

**Layout:**
- **Left panel**: Run Inventory (character's current loadout, 250 weight capacity)
- **Right panel**: Stash (persistent storage, 1000 weight capacity)

**Controls:**
- Arrow keys: Navigate between panels and items
- Enter/E: Select item → Move to other inventory
- S: Sell selected item (from either inventory) for base value
- Tab: Switch to Contracts screen
- Space: Enter Zone (with current run inventory contents)
- ESC: Quit game

**Display:**
- Each item shows: Name, Weight, Value (if applicable)
- Weight totals: "Run Inventory: 60/250" and "Stash: 320/1000"
- Current money displayed at top

**Weight Management:**
- No weight restrictions in base hub (can freely move items between inventories)
- If run inventory exceeds 250 capacity when entering zone, player cannot move until weight is reduced
- Existing overweight logic from zone gameplay handles this restriction

### 2. Contracts (separate tab)

**Layout:**
- **Active Contracts** section (up to 3)
  - Shows contract description + reward
- **Available Contracts** section (5 random options)
  - Shows contract description + reward

**Controls:**
- Arrow keys: Navigate between contracts
- E: Select available contract (max 3 active) OR Turn in items for active contract
- Tab: Return to Stash Management screen
- ESC: Return to Stash Management screen

**Contract Turn-in:**
- When E pressed on active contract, validates player has required items (from either inventory)
- Consumes items, awards money, marks contract complete removing it from the Active Contracts list
- Message log: "Contract complete! Earned <reward> rubles for completing: <description>"

## Money System

**Run Money** (current stalker's earnings)
- Starts at 0 each new stalker
- Earned by selling items and completing contracts
- Displayed prominently in base hub
- **Resets on death**
- Pure score/achievement (no spending... yet)


## Contract System

### Contract Pool Generation
- 5 random contracts available at any time
- Generated when player first opens the Contracts screen on the current stalker
- A new random contract is generated each time the player marks a contract as active (always maintaining 5 available)
- Resets when the current stalker dies
- Player can have up to 3 active contracts simultaneously

### Contract Types (examples)

| Contract | Description | Reward | Bonus vs Selling |
|----------|-------------|--------|------------------|
| Battery Runner | Retrieve 5 batteries | 25 rubles | +10 (vs 15) |
| Scrap Haul | Bring back 100 weight of scrap | 100 rubles | +50 (vs 50) |
| Relic Hunt | Collect 1 Fully Empty | 300 rubles | +100 (vs 200) |
| Detector Recovery | Retrieve 2 metal detectors | 150 rubles | +50 (vs 100) |

**Reward Formula**: Contract rewards should be ~1.3-1.5x the item's sell value to incentivize completion

### Contract Mechanics
- **Selection**: Choose up to 3 active contracts any time in base
- **Turn-in**: In Contracts screen, select active contract and press E
  - Validates items exist (in run inventory OR stash)
  - Consumes items from either inventory
  - Awards money, marks contract complete
  - Contract removed from active list (slot opens for new contract)

## Permadeath Rules

**When player dies in zone:**

1. **Lost forever:**
   - Run inventory (everything carried at time of death)
   - Base stash (all stored items)
   - Active contracts
   - Run money
   - Map state (restore map from the saved state)

2. **Fresh start:**
   - New stalker spawns
   - Run inventory has starter loadout (10 bolts + metal detector)
   - Empty stash (1000 capacity)
   - No active contracts
   - New contract pool (5 random)
   - Money = 0

## Item Flow

### First Run (New Stalker)
```
Run Inventory: 10 Bolts (10 weight) + Metal Detector (50 weight) = 60 total
Stash: Empty
```

### Post-Extraction Flow
1. Return to Base Hub (Stash Management screen)
2. Run inventory contains everything extracted from zone
3. Player manually manages items:
   - Move items: run inventory → stash (if space available)
   - Move items: stash → run inventory (prepare for next run)
   - Sell items from either inventory (S key)
4. Switch to Contracts tab:
   - Turn in items for active contracts (E key)
   - Select new contracts if slots available
5. Return to Stash Management:
   - Ensure run inventory has desired loadout
   - Press Space to Enter Zone

### Pre-Run Loadout Prep
- Run inventory IS your loadout
- Move items from stash → run inventory (manual, style)
- Can enter with empty run inventory if desired (hardcore mode)
