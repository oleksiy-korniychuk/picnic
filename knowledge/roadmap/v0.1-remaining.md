# Work items

## 1. Stash system resource

* Create a `Stash` resource with `items: Vec<Item>` and `capacity: u32` (1000).[^progression]
* Initialize an empty stash on a new stalker; persist the stash between runs (until death); reset it on permadeath.[^progression]

## 2. Money system

* Create a `RunMoney` resource (u32, tracks the current stalker's rubles).[^progression]
* Display the real money value in the base hub UI (replace the placeholder).[^progression]
* Reset money on permadeath; update the display after selling items and completing contracts.[^progression]

## 3. Item management in the base hub

* Replace placeholder items with real inventory + stash data.[^progression]
* Arrow key navigation between panels and items.[^progression]
* Enter/E moves the selected item between run inventory ↔ stash; S sells the selected item from either inventory (adds to RunMoney).[^progression]
* Update weight displays dynamically; handle edge cases (full inventories, item not found, etc.).[^progression]

## 4. Contract system expansion

* Add `available_contracts: Vec<Contract>` to the ContractSystem; add a `reward: u32` field to the Contract struct.[^progression]
* Generate 5 random contracts on a new stalker from the contract pool (see [contracts](/design/contracts.md)):[^progression]
  * Battery Runner: 5 batteries → 25 rubles.
  * Scrap Haul: 100 weight of scrap → 100 rubles.
  * Relic Hunt: 1 Fully Empty → 300 rubles.
  * Detector Recovery: 2 metal detectors → 150 rubles.
* Regenerate one contract when the player activates one (maintain 5 available).[^progression]
* Arrow key navigation in the contracts UI; E on an available contract activates it (if fewer than 3 active); E on an active contract turns in items (validate, consume, award money).[^progression]
* Display real contracts in the UI (replace placeholders).[^progression]

## 5. Permadeath integration

* ✅ Death triggers the full reset (stash clear, starter loadout, contract/turn/log reset) via the `permadeath` marker on `AutoRestartFlag`; extraction preserves the run inventory (both verified live 2026-10-06, see [status snapshot](/status/current-state.md#verification)).[^progression]
* ⏳ Remaining once items 2/4 land: reset RunMoney to 0 and generate a new contract pool on death (currently `contract_system.reset()` only clears completed flags).
* Design update (2026-10): on death, map knowledge persists - only stash, money, contracts, and loadout reset.[^board-2025-12-04] The POC map is static so current behavior is equivalent, but the death-path reset must preserve explored state rather than resetting the map once exploration tracking or world changes land. Post-v0.1, permadeath evolves into the [apprentice succession system](/design/apprentices.md).

## 6. Polish and integration

* Remove placeholder UI content; integrate real data from Inventory, Stash, RunMoney, and ContractSystem.[^progression]
* Rebuild the UI systems to be data-driven.[^progression]
* Add proper error handling and validation.[^progression]
* Update the message log for base hub actions (sold item, completed contract, etc.).[^progression]
