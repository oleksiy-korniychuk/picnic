# Picnic
A roguelike game inspired by Roadside Picnic, built with Rust and Bevy.

## Stack
This game uses the `bevy` game engine (v0.16.0) with its ECS framework.

## Status
Currently in early development - cleaning up infrastructure and preparing for core gameplay implementation.
